# ChatAppPart1 - Student Chat Application
## Overview
ChatAppPart1 is a Java-based application designed to manage user registration, authentication, and contact validation. The project features input validation rules, secure login checks, and unit test coverage to ensure system reliability.

## Application Features
* **User Registration**: Captures user credentials including username, password, first name, last name, and cellphone number.
* **Authentication**: Verifies login credentials and returns formatted status message upon successful or failed attempts.
* **Input Validation Logic**:
* **Cell Phone Number**: Validates international/local South African numbers using regular expressions (regex).
* **Username & Password**: Enforces specific character limits and formatting rules.
* **Unit Testing**: Unit test suite implemented in `LoginTest.java` (JUnit 5) to verify registration, login, and validation functions.

  ## Project Structure
  * `Login.java`: Core backend logic handling user creation, password verification, and validation rules.
  * `Main.java: Application Entry point and user interaction flow.
  * `LoginTest.java`: Automated unit test covering success and failure cases for authentication and validation.
